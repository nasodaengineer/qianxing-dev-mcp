# qianxing-collision-interaction

## Suggested name
碰撞、触发器与交互判定

## Suggested description
在创作者需要做踩踏机关、区域触发、物理阻挡/攀爬、投射物命中盒，或「走进去没反应」时使用。

---

## Body

### 先分清三种「碰撞」

| 概念 | 是否物理阻挡 | 用途 |
|------|--------------|------|
| **原生碰撞** | 是（精细贴模） | 基础信息开关：初始生效 / 是否可攀爬；形状不可改 |
| **额外碰撞** | 是（可拼形状） | 自定义阻挡/攀爬盒；可多段叠加；节点可开关 |
| **碰撞触发器 ↔ 碰撞触发源** | **否**（纯逻辑范围） | 进入/离开时给 **触发器所在实体** 发节点图事件 |

另：**命中检测** 组件 = 攻击/投射物命中盒（可向服务端发命中事件，或本地立刻打能力单元）。

### 逻辑触发标准配方
1. **探测方**挂 **碰撞触发器**（可多个；形状长方体/球体/胶囊体；可设初始生效、生效目标：角色/物件/造物）。
2. **进入方**挂 **碰撞触发源**（每实体同时仅一个生效）。
   - **角色、造物默认已有触发源**，物件通常要手动加。
3. 在触发器实体的服务端节点图监听：
   - `进入碰撞触发器时`
   - `离开碰撞触发器时`
4. 可用节点动态 `激活/关闭碰撞触发器` 或 `激活/关闭碰撞触发源`。
5. 例：木箱加触发源 + 地面尖刺加触发器 → 接触时尖刺收到进入事件 → 再结算伤害。

### 物理阻挡 / 攀爬
- 原生碰撞：基础信息里开关；攀爬还要求角色职业允许攀爬。
- 额外碰撞：组件 → 详细编辑 → 添加形状；可勾选可攀爬；节点按「碰撞区序号」开关阻挡或攀爬性。
- 选中额外碰撞时编辑器以蓝色显示范围。

### 命中检测（攻击盒/投射物）
- 触发类型：单次 / 每实体不重复 / 重复（配间隔）。
- **检测延迟**：防射出瞬间打到自己。
- 高速弹建议开 **CCD**（连续碰撞检测），注意性能；可按速度阈值启用。
- 可用 **本地过滤器节点图** + 阵营筛选；两者同时启用时需都通过。
- 过滤器内常用查询：自身实体、目标实体、当前角色。

### 常见坑
- 只加了触发器、进入物是普通物件却没加触发源 → 永远无事件。
- 把逻辑触发当成物理墙（或反之）。
- 触发器「初始生效」未勾选，又未用节点激活。
- 生效目标未勾选「角色」导致玩家走进无反应。
- 职业禁止攀爬时，物件可攀爬也无效。

### 协助时应索取
- 触发器与触发源两侧的组件详细编辑截图（形状/初始生效/生效目标）
- 监听进入/离开的节点图截图
- 双方实体类型（角色/造物/物件）
- 若是攻击盒：命中规则页 + 过滤器图
