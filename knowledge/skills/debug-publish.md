# qianxing-debug-publish

## Suggested name
调试、负载与发布准备

## Suggested description
在节点图逻辑异常、试玩校验失败、需要看日志/打印、评估负载与风险检查、或准备导入导出/上传关卡时使用。

---

## Body

### 调试工具箱

#### 1. 节点图日志（沙箱 → 窗口 → 日志）
1. 在筛选里勾选要监视的节点图。
2. 运行关卡/试玩，查看：节点图事件时间线、「打印字符串」输出。
3. 双击进入调试模式：选逻辑子图高亮；悬停节点看当时入参/出参。
4. 适用于：事件没进、分支走错、多对一连线导致节点执行多次、随机数重算疑惑。

#### 2. 打印字符串节点
在关键路径打点（进入触发器、加分前后、结算前），配合日志页签查看。

#### 3. 试玩校验 vs 风险检查
| | 试玩校验 | 风险检查 |
|--|----------|----------|
| 入口 | 点试玩时自动 | 系统菜单 → 风险检查 |
| 失败影响 | **阻断**试玩 | 不阻断，提示不当配置/隐藏规则 |
| 记录 | 错误码弹窗 | 最多 5 条检查记录，重载存档清空 |

#### 4. 负载
- **编辑期**：关卡设置 → 基础配置 → 负载设置（选择游玩所需最低负载档；档越高告警上限越高）。
- **沙箱负载检测**：记录节点图运行负载。
- **负载计算功能**：静态布设密度 + 运行后报告；投放详情会展示负载需求并提示玩家。
- 优化思路：布景改静态实体、降低场景生成密度、减少同时生效的动态组件/CCD、合并节点图逻辑、避免每帧重逻辑（用事件/定时器）。

### 导入导出与协作
- 详见 sandbox-basics：`.gia`、组合包、引用关系同包导出。
- 交接给协作者：导出玩法相关 **动态元件 + 节点图** 组合包，并注明挂载关系与依赖的信号名/变量名。

### 上传 / 发布前清单
1. 风险检查清零或确认可接受项。
2. 单人试玩完整走通：开局 → 核心循环 → 结算。
3. 多人若需要：多人试玩；注意房间未解散时不能单人试玩。
4. 检查关卡结算状态与外围系统（排行榜/段位）是否按设计更新。
5. 负载档位与实际布设匹配；模型可见性/负载优化项（若用了）。
6. 系统菜单保存存档 → 上传关卡。

### 常见故障树
- **事件不触发**：未挂载图 / 挂错实体 / 触发源缺失 / 触发器未生效 / 生效目标未勾选 / 看日志是否完全无事件。
- **变量不变**：写错实体或变量名；容器引用修改未 Set；本地图尝试写入。
- **试玩进不去**：读错误码；多人房间占用；校验资源缺失。
- **技能逻辑偶发丢**：节点图事件轨道跳过 → 结束轨道兜底。
- **性能告警**：查负载报告热点区域与高频节点图。

### 协助时应索取
- 日志窗口截图（含筛选的节点图名与打印输出）
- 试玩错误码全文 / 风险检查条目
- 负载设置与告警截图
- 问题复现步骤（几人、哪一帧操作）
