# qianxing-node-graphs

## Suggested name
节点图类型与挂载

## Suggested description
在创作者需要编写/挂载节点图、区分服务器与客户端节点图、理解执行流/运算流、或节点图「写了但不生效」时使用。

---

## Body

### 何时启用
- 「节点图挂在哪」「服务端/客户端差在哪」「过滤器怎么用」
- 事件不触发、连线报类型错误、随机数每次结果异常、跨子图传参出错

### 节点图是什么
自定义逻辑载体。要素：
- **节点**：原子功能（播放特效、加法、循环…）
- **执行流连线**（白）：逻辑顺序
- **运算流连线**（蓝）：参数传递
强类型：只有同类型参数引脚才能直连。

### 类型总表（必记）

| 类型 | 运行侧 | 挂载位置 | 生命周期要点 |
|------|--------|----------|--------------|
| 实体节点图 | 服务端 | 实体/元件 → 节点图页签 | 随实体销毁失效 |
| 单位状态节点图 | 服务端 | 单位状态 → 通用信息 | 状态移除即失效 |
| 职业节点图 | 服务端（超限） | 自定义职业 → 节点图；可选玩家/角色 | 换职业后旧图失效 |
| 道具节点图 | 服务端 | 战斗预设 → 道具 → 基础设置 | 随道具配置 |
| 角色/造物技能节点图 | 客户端 | 技能动画编辑 → 节点图事件轨道 | 动画跑到时点才跑 |
| 造物状态 / 决策节点图 | 客户端 | 复杂造物特化配置 / 决策节点内 | 自主行为 |
| 本地过滤器（布尔/整数） | 客户端 | 组件内（如命中检测、选项卡） | 返回值决定业务是否生效 |
| 角色操控技能节点图 | 客户端 | 类似角色技能 | 操控态专用；无技能动画表现 |

沙箱侧：
- **服务器节点图资源管理器**（默认）：实体/状态/职业/道具
- **客户端节点图资源管理器**（窗口菜单打开）：技能/造物状态/决策/本地过滤器

### 编辑与挂载步骤（通用）
1. 千星沙箱中按类型 **新建节点图** → 双击进入编辑。
2. 右键空白处选节点，或从引脚拖出松手做「类型匹配快速创建」。
3. **保存**节点图。
4. 到对应挂载入口「新增/选择」该节点图。
5. 未挂载 = 不运行。

### 运行模型（协助排错用）
- **服务端图**：必须从 **事件节点** 起步；事件多半只响应该图所挂实体上的事。
- **技能图**：从固定「节点图开始」跑到结束，非事件驱动。
- **过滤器图**：只有运算流 +「节点图结束」出口；布尔 TRUE 才让业务生效；整数型需输出落在业务配置的整数列表内。
- **逻辑子图**：一张图可有多个从事件出发的子图；**禁止跨逻辑子图做运算流连线**（会读到过期值）。
- 执行流一对多 = **深度优先**顺次执行；多对一会导致同一节点被跑多次（用日志确认）。
- **不可成环**（跳出循环节点除外）。
- 节点执行失败会用类型默认值，但 **不中断** 后续执行流。
- 运算流只在被某执行节点入参引用时求值；同一执行节点内共享运算流只算一次，不同执行节点会 **重算**（随机数场景尤其明显）。

### 数据类型速记
实体 / GUID / 整数 / 布尔 / 浮点 / 字符串(最长约40英文字符) / 三维向量 / 元件ID / 配置ID + 各列表型。  
浮点溢出修正为 0（非 Inf/NaN）。列表下标从 0；列表/字典/结构体为 **引用传值**（见变量技能）。

### 常见坑
- 只创建节点图未挂载；或挂在错误实体。
- 职业节点图仅 **超限模式**；角色技能节点图同理（造物技能经典+超限都可）。
- 过滤器与阵营筛选同时开时需 **同时满足**。
- 技能「节点图事件轨道」极小概率跳过事件 → 关键逻辑放 **结束事件轨道** 兜底。
- 改完图未保存 / 实体仍挂旧 ID。

### 协助时应索取
- 节点图全图截图（含事件起点与挂载目标说明）
- 沙箱里该图是服务端还是客户端分类
- 挂载入口截图（实体节点图页签 / 技能时间轴 / 组件过滤器槽）
- 「预期触发条件」一句话（例如：玩家走进触发器）
