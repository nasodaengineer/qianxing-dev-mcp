# qianxing-sandbox-basics

## Suggested name
千星沙箱与编辑器基础

## Suggested description
在创作者刚打开千星奇域编辑器、需要认识界面/模式切换、创建与摆放实体、试玩与导出资产、或找不到千星沙箱入口时使用。

---

## Body

### 何时启用本技能
- 用户问「编辑器怎么开」「沙箱在哪」「怎么试玩/保存/导出」
- 用户对地形编辑 / 实体摆放 / 元件库 / 战斗预设四个模式不清楚
- 需要指导从零创建一个可试玩的空关卡骨架

### 关键概念（官方用语）
- **系统菜单**：左上角菜单或 `Esc`。含保存/打开存档、上传关卡、千星沙箱、关卡设置、试玩、资产导入导出、风险检查等。
- **四个编辑模式**（顶栏切换）：
  1. **地形编辑**：地形、环境、物件/造物布设
  2. **实体摆放**：物件/掉落物/造物布设；部分玩法功能仅在此页签可用
  3. **元件库**：新建/修改物件元件、造物元件、掉落物元件、元件组
  4. **战斗预设**：玩家模板与职业、单位状态、技能、本地投射物、道具
- **动态实体 vs 静态实体**：
  - 动态：可挂组件与节点图，有 GUID，可被节点图操作，更耗性能
  - 静态：不可挂组件/节点图，无 GUID，省性能，适合纯布景
- **千星沙箱**：逻辑创作中枢（默认进入编辑时开启；关闭后从系统菜单左下打开）
  - 左：资源管理器（局内实体/元件）
  - 右：服务器节点图资源管理器（默认）
  - 窗口菜单还可开：客户端节点图资源管理器、节点管理器、日志、服务器信号管理器、负载检测

### 推荐操作流程（创建 → 试玩）
1. 系统菜单 → 确认存档已保存。
2. 在 **元件库** 用预制动态元件复制出玩法物件，或直接在 **实体摆放** 拖入动态单位。
3. 需要逻辑时：打开 **千星沙箱** → 创建实体节点图 → 在实体/元件「节点图」页签挂载。
4. 系统菜单 → **试玩**：通过校验与上传后，配置试玩玩家编号、临时存档、是否跳过装扮展示/结算等。
5. 局内用左上退出或 `Esc` 打开试玩控制：继续 / 重新挑战 / 中断挑战。
6. **多人试玩房间未解散时无法单人试玩**。

### 资产导入导出（.gia）速查
- **导出入口**：右键（地形/实体/元件/沙箱节点图/战斗预设技能状态道具）或「系统菜单 → 资产导入导出工具」。
- 单选/多选均可导出为 `.gia`；多选会成 **组合资产**。
- **关联项**：导出元件时挂载的节点图一并导出；导出实体时归属元件与节点图一并导出。
- **导入**：导入与转存页签 → 加载外部资产。注意：每次本地导入会 **清空** 沙箱资产库页签内已有外部资产再刷新。
- **引用关系**：有互相引用的资产应打成同一组合包导出，导入后 GUID 引用会按组合内关系恢复。

### 常见坑
- 误用静态实体做机关 → 无法挂节点图/无 GUID。
- 改完节点图忘记在沙箱中 **保存**，实体页签仍指向旧图。
- 试玩前未通过校验（错误码会弹出）；风险检查 ≠ 试玩校验（前者不阻断试玩）。
- 镜头：WASD 移动，QE 升降，右键旋转，中键平移，滚轮推拉，`Alt+L` 水平锁。

### 协助创作者时应索取
- 当前处于哪个模式页签的截图（顶栏）
- 系统菜单是否已打开千星沙箱
- 试玩失败时的错误码/弹窗全文
- 若谈导入导出：`.gia` 是单资产还是组合包、导出时勾选了哪些项
