# qianxing-scene-generation

## Suggested name
场景生成模板

## Suggested description
在创作者需要快速铺大面积场景、用预设/自定义场景生成模板、调密度与伴生植被，或生成后批量移动/删除生成物时使用。

---

## Body

### 功能一句话
用模板按层（岩石→建筑→树木→植被→装饰…）在指定范围内批量散布模型，适合布景而非精细玩法摆放。

### 使用预设模板
1. **实体摆放** →「场景生成模板」→「预设模板」→ 导入。
2. 在未分类/自定义页签点击或拖拽模板，生成实例。
3. 选中实例：
   - **基础属性**：生成规则、生成范围（长方体/圆柱）
   - **资产配置**：每层密度、随机性、资产种类等
4. **随机预览** → 满意后 **确认生成**。
5. 生成后可用场景实体组右上角 **全选 / 删除** 整批调整。

### 自建模板
1. 实体摆放 → 场景生成模板 → **管理模板**，或系统菜单「场景生成模板管理」。
2. 新建 → 资产配置 → 保存。
3. 之后在资产栏「场景生成模板」页签使用。

### 关键参数
- **散布规则**：可预览并「保存散布规则」复用；「锁定生成结果」可每次生成完全相同。
- **层密度**：越小越稀，越大越密。
- **生成随机性**：0 偏均匀，1 偏杂乱。
- **岩石层「是否基于地形生成」**。
- **植被层伴生范围**：以树木层物件为圆心；树木间隔过大或伴生范围过小 → 植被不生成。可减小树木「生成间隔距离」（可为负）或增大伴生范围。
- **权重 / 生成间隔距离 / 变换区间**：在层「详情编辑」里调；间隔 = 当前物件包围盒半径 + 该值 的禁生圈，影响下一层。

### 特殊规则（必读）
1. 层 **依次** 生成；除岩石外遵循 **剔除规则**——在上一层空隙生成。上一层过密会导致下层没地。
2. 植被层特殊：**伴生树木层**；树木不生成则植被也不生成。

### 与玩法摆放的边界
- 生成物偏布景；要做机关请另用动态实体 + 组件/节点图。
- 大面积生成注意 **负载**（见 debug-publish 技能）。

### 协助时应索取
- 基础属性 + 资产配置面板截图
- 出问题的层（尤其树木/植被）详情编辑
- 「随机预览」结果截图与期望密度描述
