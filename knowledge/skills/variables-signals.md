# qianxing-variables-signals

## Suggested name
自定义变量、节点图变量与信号

## Suggested description
在创作者需要存分数/开关状态、在实体间通信、区分自定义变量与节点图变量、或配置服务器信号解耦逻辑时使用。

---

## Body

### 三层数据/通信怎么选

| 手段 | 生命周期 | 可见范围 | 典型用途 |
|------|----------|----------|----------|
| **自定义变量**（组件） | 随实体 | 全局可读可写（指定实体） | 得分、机关计数、需跨图共享的实体数据 |
| **节点图变量**（仅服务端图） | 随节点图 | 仅本图内 | 临时列表、封装模块内部状态；可「对外暴露」供关卡覆写 |
| **信号** | 全局定义 | 任意服务端图发送/接收；技能图也可向服务端发 | 一机关多响应、解耦多方逻辑 |

### 自定义变量
1. 实体/元件 → 组件页签 → **自定义变量**（单位默认常已挂载）→ 详细编辑。
2. 定义：变量名（同组件不重名）+ 类型 + 默认值。
3. **只有组件里预先定义的变量会同步到本地**，供界面/本地过滤器使用；服务端可用「设置自定义变量」动态新建（勿与现存重名）。
4. 节点：设置 / 获取 /「自定义变量变化时」。
5. 要点与坑：
   - 改名/改类型/删除可能导致节点找不到变量而静默失败。
   - 「变化时」在值被设为相同值时也会触发；应用分支按 **变量名** 过滤。
   - 容器类型（列表/字典/结构体）：获取后是 **引用**；对列表插入/排序会改原变量，但 **不触发**「变化时」；只有「设置自定义变量」才触发，且容器的变化前/后值出参为空，需再 Get。
   - 整数在组件中不能取到 -2147483648；浮点设置精度 0.0001。
   - 本地节点图 **只能读** 自定义变量，不能写。

### 节点图变量
- 入口：节点图编辑 → 快捷菜单 → 节点图变量页签。
- 同图内不重名；不同图可以同名。
- 可点「对外暴露」后在关卡实体上覆写（例：同炸药桶图、不同伤害）。
- 推荐：实体通用数据 → 自定义变量；图内临时/封装数据 → 节点图变量。

### 信号（服务器信号管理器）
1. 千星沙箱 → 窗口 → **服务器信号管理器**（或节点图快捷菜单「信号管理」）。
2. 新建信号：信号名 + 任意数量参数（合法节点图类型）。
3. 节点：「发送信号」选信号名后出现对应入参；「监听/接收信号」出现对应出参。
4. 技能（客户端）节点图也可「向服务器节点图发送信号」，所有服务端图可监听。
5. 设计思想：发送端只广播「发生了什么」；各实体各自监听并处理 → 避免一个机关节点图直接操作全世界。

### 协助时应索取
- 变量定义面板截图（名/类型/默认值）
- 读写该变量的节点图局部截图
- 若用信号：信号管理器中该信号的参数列表 + 发送端/接收端图
- 说明数据是「只要本机关用」还是「别的实体也要读」
