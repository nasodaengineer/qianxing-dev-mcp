# 一、界面动效的功能

*界面动效*可以配置在界面布局中，并在界面布局中显示对应的特效资产，是用于美化、丰富表现而使用的一种界面控件

在关卡运行中，可通过节点图唤起界面动效控件

## 2.界面动效设置

![img](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mh2iyk9fa4gy/346044df-3026-40a5-90f4-69d9930e96a3.png)

*选择界面动效*：可以选中所需要展示在界面布局中的特效资产

*是否播放音效*：选是则会同步播放该资产自带的音效

*层级*：仅支持在所有控件之上/在所有控件之下，默认在所有控件之上
